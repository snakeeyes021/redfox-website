Not sure which one? Help me choose

Run one command on the computer you'll install RedFoxOS on. It lists the computer's graphics and prints a short code; paste the code below. Nothing runs, and nothing leaves your computer, unless you do this. The code is only the graphics chips' ID numbers.

On Linux, in a terminal

curl -sL https://raw.githubusercontent.com/snakeeyes021/redfox-os/main/extras/identify_gpu.sh | bash

On Windows, in PowerShell

irm https://raw.githubusercontent.com/snakeeyes021/redfox-os/main/extras/identify_gpu.ps1 | iex

Want to read them first? identify_gpu.sh, identify_gpu.ps1.

Then

  1. Write the image to a USB stick of 16 GB or more with Fedora Media Writer or balenaEtcher. Everything on the stick is erased.
  2. Start the computer from the stick (often F12, F11 or Esc at power-on). It needs UEFI, not legacy/CSM mode.
  3. Choose Install RedFoxOS, pick the disk, and create your account.
  4. Restart. With Secure Boot on, a blue screen asks once to enrol a key: Enroll MOK, Continue, Yes, password universalblue, Reboot.
  5. Your apps install in the background at the first start, once you're online.

These are the stable images. For the unstable channel, install stable, then run ujust rollback-helper rebase unstable. Already on Bazzite or Bluefin (GNOME)? You can rebase instead.
