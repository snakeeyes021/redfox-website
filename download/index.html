Not sure which one? Help me choose

On the machine you plan to install RedFoxOS on, run one of these commands. It'll hand you the name of the download that works best for your machine.

On Linux, in a terminal

curl -sL https://raw.githubusercontent.com/snakeeyes021/redfox-os/main/extras/identify_gpu.sh | bash

On Windows, in PowerShell

irm https://raw.githubusercontent.com/snakeeyes021/redfox-os/main/extras/identify_gpu.ps1 | iex

Want to read them first? identify_gpu.sh, identify_gpu.ps1.

Then

  1. Write the image to a USB stick with Fedora Media Writer or balenaEtcher. Everything on the stick is erased.
  2. Start the computer from the stick (often F12, F11 or Esc at power-on). It needs UEFI, not legacy/CSM mode.
  3. Choose Install RedFoxOS, pick the disk, and create your account.
  4. Restart. With Secure Boot on, a blue screen asks once to enrol a key: Enroll MOK, Continue, Yes, password universalblue, Reboot.
  5. RedFox installs a small set of core apps in the background on first boot, once you're online.

These are the stable images. For the unstable channel, simply switch to unstable in RedFox Hub after installation. Already on Bazzite or Bluefin (GNOME)? You can rebase instead.
