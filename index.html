Installer · Music notation

Torquio

Dorico is a wonderful piece of notation software that doesn't officially run on Linux. Under Wine it actually runs fine. The hard part is getting past the installers, account logins and license handoffs. Torquio automates all of that, reproducibly, inside a Distrobox container so you can focus on making music.

View on GitHub
git clone https://github.com/snakeeyes021/torquio.git

A Flatpak is on the way. For now, clone it and follow the README.

Operating system · Built on Bazzite

RedFox OS

The computer we actually want to work on. It's Bazzite with a full developer setup (containers, virtual machines, dev tools), plus curated app packs and our own projects built in. It still supports older Pascal-era Nvidia cards, which the other developer spins have dropped.

It's an atomic system, so updates happen all at once and you can always roll back.

How to install
rpm-ostree rebase ostree-image-signed:docker://ghcr.io/snakeeyes021/redfox-os:latest

Rebase from a GNOME-based Universal Blue system. Nvidia users, see the install notes for your image.

MIDI player · For keyboardists

Pianola

It's a midi player. Nice and simple. It felt like there weren't any good, clean, and modern midi players out there for Linux, so we made one. It's got a few neat little features that we think stand out. It shows markers on the piano roll view, it can flip between multi-channel and piano reduction view, it'll let you scrub the audio with ctrl-space just like engraving software, and it's got decent sounds (FluidSynth), among a few other things.

On RedFox OS it pairs with Midikeep, which quietly records everything you play. Pianola then becomes a scrollable diary of every take, going back days, months or years.

Get the Flatpak or install it from RedFox OS

Personal assistant · Day planner

Thirties

Humans naturally live in half-hour chunks. If alien anthropologists studied us without knowing about clocks, they'd decide our unit of time was thirty minutes. Thirties starts there: it lays your day out as "thirties" between sunrise and sunset. Clock times play second fiddle.

You plan the day with it in plain conversation. It keeps your to-do list and schedule, moves only what needs moving when plans gang aft agley, helps with long-term planning, and can text you on Telegram. Think of it as the off-gridder's Siri. It's heading toward running entirely on your own machine.

Get the Flatpak or install it from RedFox OS
